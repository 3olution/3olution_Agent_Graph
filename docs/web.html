Web Frontend

The complete browser interface for the 3olution Agent Graph. Three self-contained pages — Chat at /, Graph Editor at /graph, Settings at /settings — served as plain HTML, CSS, and JavaScript. No bundler, no transpilation, no framework. Every page works in any modern browser and can be cached independently. The only vendored dependency is LiteGraph.js, and it has a CDN fallback if it is missing.

Overview

The web/ folder holds the entire browser-facing frontend of the 3olution Agent Graph. Three HTML pages, three stylesheets, three scripts, and one vendored JavaScript library. Together they provide a chat client, a visual graph editor, and a settings page — all talking to the same FastAPI backend over HTTP, WebSocket, and Server-Sent Events.

Design principles

  • No build step. Every file is served directly. No webpack, no Vite, no Babel, no TypeScript. What you edit is what the browser runs.
  • No shared JavaScript. Each page has its own script and its own stylesheet. There is no common.js or shared.css. A change to the chat page cannot break the graph editor.
  • One vendored dependency. LiteGraph.js is the only third-party library. It is downloaded on demand and has a CDN fallback if the local copy is missing.
  • Same origin. The pages are served from the backend, so no CORS configuration is needed for the default deployment. No cookies, no tokens, no authentication layer.
  • Dark theme throughout. The three stylesheets share the same CSS variables (--bg, --accent, --green, etc.) by convention, though each file defines its own copy.

What each page talks to

Graph Editor WebSocket + REST /ws/graph, /api/graph/*, /api/llama/all-models, /api/system/stop-all
Settings REST + SSE /api/llama/install/*, /api/ollama/*

Browser support

The pages work in any modern browser released after 2020: Chromium 90+, Firefox 90+, Safari 15+. The features used:

  • fetch() with ReadableStream bodies (for SSE)
  • WebSocket API
  • CSS custom properties, grid, flexbox
  • localStorage
  • Optional chaining (?.), nullish coalescing (??)
  • navigator.clipboard.writeText()
Everything is progressive. If LiteGraph fails to load, the graph editor shows a friendly error. If the backend is unreachable, each page displays a diagnostic. If localStorage is disabled, sessions are ephemeral but the app still works.

Clipboard fallback

The Copy button uses navigator.clipboard.writeText() where available, and falls back to a hidden textarea plus document.execCommand("copy") for older browsers and non-HTTPS contexts: 

async function copyToClipboard(text) {
    try {
        if (navigator.clipboard && navigator.clipboard.writeText) {
            await navigator.clipboard.writeText(text);
            return true;
        }
    } catch (err) { /* fall through */ }
    try {
        const ta = document.createElement("textarea");
        ta.value = text;
        ta.style.position = "fixed";
        ta.style.top = "-9999px";
        document.body.appendChild(ta);
        ta.select();
        const ok = document.execCommand("copy");
        document.body.removeChild(ta);
        return ok;
    } catch (err) {
        return false;
    }
}

The stall timeout

Every agent turn is wrapped in a stall timer. If no event arrives for six minutes, the UI assumes the turn is stuck and resets: 

function resetStallTimer() {
    if (stallTimer) clearTimeout(stallTimer);
    stallTimer = setTimeout(() => {
        if (busy) {
            streamingBubble = null;
            thinkingBubble = null;
            addMessage(
                "⚠ No response for 6 minutes. Try a different model, " +
                "or click Stop.",
                "info",
            );
            setBusy(false);
        }
    }, STALL_TIMEOUT_MS);
}

This mirrors the backend's own stall timeout (AGENT_STREAM_STALL_TIMEOUT), which aborts the turn server-side. The client-side timer is a safety net for the case where the WebSocket itself hangs.

Model Picker — the provider::model Encoding

The model picker lists every model the backend can reach: every Ollama model plus every local GGUF file. Each entry is tagged with its provider, and the option value is an encoded string rather than a bare model name.

The encoding

ollama::llama3.2
llama_cpp::llama-2-7b-chat.Q4_K_M.gguf
llama_cpp::qwen2.5-coder-7b.Q4_K_M.gguf

The :: separator lets the client:

  • Display a single flat list without grouping markup.
  • Parse the provider and model name in one step.
  • Route the request correctly regardless of which dropdown group the user picked from.

Parsing

parseModelSelection() splits the value on the first ::: 

function parseModelSelection() {
    const v = modelSelect.value;
    if (!v) return { provider: "auto", model: null };

    const idx = v.indexOf("::");
    if (idx < 0) return { provider: "auto", model: null };

    return {
        provider: v.slice(0, idx),
        model: v.slice(idx + 2),
    };
}

The provider (left side) goes into the outgoing message's provider field; the model (right side) goes into model. An empty value means "use the default model".

Grouped display

The dropdown groups entries by provider using native <optgroup> elements: 

<optgroup label="Ollama (3)">
    <option value="ollama::llama3.2">llama3.2  (4.7 GB)</option>
    <option value="ollama::qwen2.5">qwen2.5  (4.7 GB)</option>
</optgroup>
<optgroup label="Local GGUF (2)">
    <option value="llama_cpp::llama-3.2-3b.Q4_K_M.gguf">✓ llama-3.2-3b.Q4_K_M.gguf  (2.01 GB, loaded)</option>

Graph Editor — the LiteGraph Adapter Contract

The adapter layer in web/graph.js exists because LiteGraph's serialisation format differs from the backend's in several ways. The adapter translates between them, so neither side has to know about the other's quirks.

The differences

Concern LiteGraph Backend
Node position pos: [x, y] position: [x, y]
Node type type: "Category/name" or type: "name" type: "name"
Node params properties: { name: value } params: { name: value }
Edges Links indexed by ID in lg.links edges: [{ from_node, from_output, to_node, to_input }]
Type names Derived from registerNodeType argument Exact NodeType.name

graphFromLiteGraph() performs the forward translation; loadGraphIntoLiteGraph() performs the reverse.

The _backendId mechanism

Every LiteGraph node gets a stable _backendId property the first time it is serialised. This identifier is what the backend uses to track nodes across serialize / deserialize cycles.

Without it, newly added nodes would receive auto-incrementing LiteGraph IDs that collide with existing backend IDs on the next run: 

node._backendId = node._backendId ||
    `n${node.id}_${Math.random().toString(36).slice(2, 6)}`;

The composite form — the LiteGraph id plus a short random suffix — guarantees uniqueness even when LiteGraph reuses an id after a delete-and-add cycle.

Dynamic model widget

The llm.chat node's model widget has a dynamic: "all.models" attribute. The adapter fills its choices from the unified model list fetched at page load: 

if (widget.dynamic === "all.models") {
    const ids = state.allModels.map(m => m.id);
    return ["(default)", ...ids];
}

Each option's value is the same provider::model encoding the chat page uses. When the graph is serialised, the adapter splits the value back into two params: 

if (params.model && params.model.includes("::")) {
    const [provider, model] = params.model.split("::", 2);
    params.model = model;
    if (!params.provider || params.provider === "auto") {
        params.provider = provider;
    }
}

History and replay

The right-hand inspector shows two stacked panels:

  • Current Run — live-streamed events from the active graph execution. Status updates, errors, and the final result appear here in real time.
  • History — a scrollable list of past runs from /api/graph/runs. Each entry shows the graph name, timestamp, node count, status (green/red dot), and a truncated preview of the final output.

Clicking a history entry calls /api/graph/runs/{run_id} and replays the full event stream into the Current Run panel, additionally restoring the node statuses and painting the final result in the result bar. This makes it possible to inspect what happened in any past run without re-executing it.

The result bar

The result bar appears at the bottom of the graph page when a run completes. It contains the text from the first output.text node and has two buttons:

  • Copy — copies the result to the clipboard, with a "Copied!" confirmation for 1.4 seconds.
  • Close (✕) — hides the bar.

Persistence

The graph is auto-saved to localStorage under 3olution-graph-seed-v1 on every edit, via LiteGraph's onAfterChange hook. On page load, the editor restores the saved graph. If the saved JSON is corrupt, it falls back to a seed example.

A one-time migration clears the saved graph when the seed version number changes: 

if (localStorage.getItem(SEED_VERSION_KEY) !== CURRENT_SEED_VERSION) {
    localStorage.removeItem(SEED_KEY);
    localStorage.setItem(SEED_VERSION_KEY, CURRENT_SEED_VERSION);
}

This lets a new release ship a different default graph without users having to click Clear manually.

Save and Load

The Save button serialises the canvas and downloads a 3olution-graph.json file. The Load button opens a file picker and feeds the chosen file through loadGraphIntoLiteGraph(). Both round-trip through the same adapter contract the WebSocket uses.

Stop All

The red Stop All button behaves identically to the chat page's Stop button: confirm, then POST to /api/system/stop-all, then wait for the connection to drop. The backend logs the shutdown sequence and terminates the MCP and llama-cpp subprocesses before exiting.

Settings Page — Two Independent Installers

The settings page manages two different kinds of installable artifacts. Both use the same streaming transport (Server-Sent Events), but they consume different upstream sources.

Card Backend endpoint Streaming method Purpose
LLM Runtime /api/llama/install/* SSE (install/uninstall events) pip install llama-cpp-python with the right wheel
Pull a Model /api/ollama/models/pull SSE (Ollama NDJSON) Download a model from the Ollama registry

Both are consumed by the same streamSSE() helper, which parses data: lines and dispatches JSON frames to a callback. This is the web equivalent of the desktop client's SSEWorker in install_dialog.py.

The generic SSE consumer

The helper reads the response body as a stream, buffers text, and splits on the SSE frame separator (\n\n): 

async function streamSSE(url, options, onEvent) {
    const res = await fetch(url, options);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);

    const reader  = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = "";
    let done = false;

    while (!done) {
        const chunk = await reader.read();
        if (chunk.done) break;

        buffer += decoder.decode(chunk.value, { stream: true });
        const frames = buffer.split("\n\n");
        buffer = frames.pop();

        for (const frame of frames) {
            for (const line of frame.split("\n")) {
                if (!line.startsWith("data: ")) continue;
                const payload = line.slice(6);
                if (payload === "[DONE]") { done = true; continue; }
                try { onEvent(JSON.parse(payload)); }
                catch (err) { console.warn("Bad SSE frame:", payload, err); }
            }
        }
    }
}

The TextDecoder is called with { stream: true } so a multi-byte UTF-8 character split across two chunks is decoded correctly.

Pulling a model

The Pull card accepts a model name and streams the download progress. The backend forwards Ollama's NDJSON events to the browser as SSE frames. Progress is rendered two ways:

  • A status line showing downloading 45.2 / 214.8 MB (21.0%).

Ollama's total field is only present on the downloading event. Before that, the status line shows just the raw status string (pulling manifest, verifying sha256 digest, etc.).

Boot ordering

Three fetches run in parallel at page load: 

await Promise.all([
    loadRuntimeStatus(),   // llama-cpp install state
    loadStatus(),          // Ollama connection
    loadModels(),          // Ollama model list
]);

Because they are independent, the slowest one determines the time-to-interactive. In practice all three complete in under a second on a warm backend.

Session Persistence in the Chat UI

The chat client stores two keys in localStorage and relies on the backend for everything else.

Client-side keys

Key Value
3olution-session-id The current session's UUID
3olution-selected-model The last model the user picked
3olution-disable-tools "1" if the No-tools checkbox is on, "0" otherwise

Restoring a session

On page load, if a session ID is present, the client calls GET /api/sessions/{id} to restore the history: 

const savedSession = localStorage.getItem(SESSION_STORAGE_KEY);
if (savedSession) {
    const res = await fetch(
        `/api/sessions/${encodeURIComponent(savedSession)}`
    );
    if (res.ok) {
        const data = await res.json();
        setSessionId(savedSession);
        history = data.history || [];
        for (const m of history) {
            if (m.role === "user") addMessage(m.content, "user");
            else if (m.role === "assistant" && m.content)
                addMessage(m.content, "agent");
        }
    } else {
        await createSession();
    }
} else {
    await createSession();
}

If the session no longer exists (e.g. the SQLite file was cleared), the client creates a fresh session with a new UUID.

Creating a new session

When the user clicks + New, the client calls POST /api/sessions to get a new UUID, clears the transcript, and updates localStorage: 

async function createSession() {
    try {
        const res = await fetch("/api/sessions", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({}),
        });
        const data = await res.json();
        setSessionId(data.session_id);
        history = [];
        transcript.innerHTML = "";
        messageLog.length = 0;
    } catch (err) {
        // Offline fallback: generate a local UUID.
        const fallback = "sess-" + Math.random().toString(36).slice(2, 10);
        setSessionId(fallback);
        history = [];
        transcript.innerHTML = "";
        messageLog.length = 0;
    }
}

Automatic saves

Messages are saved to the backend automatically by the agent loop on every terminal path. The client does not need to send explicit "save" requests. Every turn ends with a final event whose messages field is the full updated history, and the backend writes that history to SQLite before emitting the event.

The session label

The header shows a short prefix of the current session ID (8b4a-...) in a monospace font. Hovering over it reveals the full UUID via a title attribute.

No server-side session list in the UI. The chat page does not expose a dropdown of past sessions. The user has one active session at a time, restored from localStorage. To switch sessions, the user must click + New and lose the reference to the old one — though the old session remains in sessions.db and can be recovered via the API.

Streaming vs. Batching

The backend exposes three transports for the same chat turn, plus a WebSocket for graph execution. All four speak the same event schema; only the framing differs.

The four transports

Transport Endpoint Used by
WebSocket /ws The web chat page
Server-Sent Events /api/chat/stream The desktop native client
Batched JSON /api/chat Command-line tools, integration tests
WebSocket (graph) /ws/graph The graph editor

The final event contract

Every agent turn ends with exactly one final event: 

{
  "type": "final",
  "content": "The answer text.",
  "messages": [
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "The answer text."}
  ]
}

The messages field is the complete updated history the client should store and send back on the next turn. It deliberately excludes the system prompt — the backend re-injects it on every turn, so changing it in code takes effect immediately without migrating stored sessions.

If the turn involved tool calls, the history also contains assistant messages with tool_calls and tool-role messages with tool_call_id. The backend handles these correctly when they are re-sent.

WebSocket framing

The chat WebSocket sends one JSON frame per event. The client parses each frame and dispatches to its event handler: 

ws.onmessage = (e) => {
    try {
        handleEvent(JSON.parse(e.data));
    } catch (err) {
        console.error("Bad event:", err, e.data);
    }
};

The connection stays open across multiple turns. After a final event, the client sends a new request frame when the user submits a message.

Graph WebSocket framing

The graph WebSocket loops: after each graph completes and is persisted, the server waits for the next payload. This makes it suitable for a live editor where the user iterates on a graph and clicks Run repeatedly.

SSE framing

The SSE endpoint emits one frame per event, in data: {json}\n\n form: 

data: {"type": "token", "content": "Hello"}

data: {"type": "token", "content": " world"}

data: {"type": "final", "content": "Hello world", "messages": [...]}

data: [DONE]

The [DONE] terminator is what tells streamSSE() to stop reading. It is emitted in a finally block so it always arrives, even if the turn raised an exception.

Batched JSON

The non-streaming endpoint collects every event into an array and returns the array as JSON. The shape is identical to the streaming events, just delivered all at once: 

[
  {"type": "token", "content": "Hello"},
  {"type": "token", "content": " world"},
  {"type": "final", "content": "Hello world", "messages": [...]}
]
The event schema is transport-independent. Any client that can consume one of the four transports can be swapped for any other without touching the parsing logic. The only difference is the framing — WebSocket frames, SSE data lines, or a JSON array.

Boot Ordering

Each page has a specific initialization sequence. Getting the order wrong breaks the page in subtle ways — a model picker with no choices, a graph editor with unregistered node types, an error on every request.

Chat page (index.html + app.js)

loadModels() → populate model dropdown
  ↓
restore session (or create one)
  ↓
connect() → WebSocket
  ↓
startBusyPolling() → poll /api/ollama/ps every 5 s

The models must load before the session is restored so that the saved model selection can be validated against the actual list. The WebSocket must connect before the user can send a message. Busy polling starts last, as it is purely cosmetic.

Graph page (graph.html + graph.js)

fetchUnifiedModels() → cache for dynamic widget choices
  ↓
GET /api/graph/litegraph-types → register all node types
  ↓
new LGraph() + new LGraphCanvas()
  ↓
restore from localStorage, or seed the example graph
  ↓
install onAfterChange → persist on every edit
  ↓
loadHistory() + loadLatestRun()

The unified model list must be fetched before node types are registered, because the llm.chat node's dynamic widget reads from that list at construction time.

LiteGraph must be imported before graph.js runs. This is done in graph.html with a local script tag plus a document.write fallback to the CDN: 

<script src="vendor/litegraph.min.js"></script>
<script>
    if (typeof LiteGraph === "undefined") {
        console.warn("Local LiteGraph not found. Falling back to jsDelivr.");
        document.write(
            '<script src="https://cdn.jsdelivr.net/gh/jagenjo/litegraph.js@master/build/litegraph.min.js"><\/script>'
        );
    }
</script>
<script src="graph.js"></script>

The document.write fallback works because it runs during page parsing, before the next script tag is evaluated. This is one of the few legitimate uses of document.write in modern web development.

Settings page (settings.html + settings.js)

Promise.all([
    loadRuntimeStatus(),    // llama-cpp install state
    loadStatus(),           // Ollama connection
    loadModels(),           // Ollama model list
])

All three requests are independent, so they run in parallel. Because they do not depend on each other, there is no ordering constraint — but running them in parallel makes the page interactive faster.

Error handling during boot

Every boot step is best-effort. A failure in one does not stop the others: 

(async function boot() {
    await loadModels();          // catches its own errors
    await restoreSession();      // falls back to a fresh session
    connect();                   // reconnects on close
    startBusyPolling();          // silently fails if backend is down
})();

The pages are designed to be usable the moment they render. If the backend is slow to start, the user sees empty placeholders with "Loading…" messages that fill in as the requests complete.

The clipboard fallback

navigator.clipboard.writeText() requires a secure context (HTTPS or localhost). On plain HTTP served from a non-localhost address, the API is undefined. The Copy buttons therefore fall back to the deprecated document.execCommand("copy") path.

The fallback works by creating an off-screen <textarea>, selecting its content, running the execCommand, and removing the textarea. It is ugly but it works in every browser, and it does not require any build-time shims.

Fonts

All three pages use system fonts and a system monospace font. There is no web font download, so the pages render instantly on first paint:

font-family: ui-monospace, "SF Mono", "Cascadia Code", Menlo, Consolas, monospace;

Serving the pages

The backend mounts web/ as a static directory at / as the last registration in backend/main.py. Because explicit routes are registered first, the /graph and /settings HTML routes win over the static mount: 

app.mount("/", StaticFiles(directory=str(WEB_DIR), html=True), name="web")

The html=True flag tells Starlette's StaticFiles to serve index.html for directory requests, so GET / returns web/index.html without any extra configuration.

Vendored assets

LiteGraph is the only external frontend dependency. It is downloaded by scripts/download_vendor.py into web/vendor/, and the two files are gitignored. If they are missing, both the CSS and the JS fall back to jsDelivr at runtime.

No build step anywhere. This is not a limitation — it is a design choice. The entire frontend can be edited in any text editor, and a change is visible on the next page reload. No dev server, no hot module reloading, no source maps to configure.

The .gitkeep convention

Empty directories do not survive in git — git tracks files, not directories. The .gitkeep file exists only so that vendor/ appears in a fresh clone.

.gitignore uses the inverse pattern to keep only the placeholder: 

web/vendor/*
!web/vendor/.gitkeep

The pattern reads "ignore everything in vendor/, then un-ignore .gitkeep". The result: the folder is tracked, the two LiteGraph files are not.

How the files get here

Three callers can trigger the download:

Caller When
bootstrap/setup.py During stage 5 of the initial install
backend/main.py In the FastAPI lifespan, if the files are missing
scripts/serve.py Indirectly — the backend does it on startup
run.py vendor Developer refresh workflow
start.sh / start.bat Portable launch, if the files are missing

All of them ultimately invoke scripts/download_vendor.py, which uses two validation gates and a two-mirror fallback chain. See the scripts documentation for the full algorithm.

<link rel="stylesheet" href="vendor/litegraph.css"

<script src="vendor/litegraph.min.js"></script>

The folder is safe to delete. Nothing in this folder holds user data. Deleting it and restarting the backend triggers a fresh download, or a fallback to the CDN if the download fails.

        const ta = document.createElement("textarea");
        ta.value = text;
        ta.style.position = "fixed";
        ta.style.top = "-9999px";
        ta.setAttribute("readonly", "");
        document.body.appendChild(ta);
        ta.select();
        ta.setSelectionRange(0, text.length);
        const ok = document.execCommand("copy");
        document.body.removeChild(ta);
        return ok;
    } catch (err) {
        console.warn("Clipboard copy failed:", err);
        return false;
    }
}


// ══════════════════════════════════════════════════════════════════════
//  Fetch with retry
// ══════════════════════════════════════════════════════════════════════
//
//  The backend may take a few seconds to accept the first request
//  while it warms up. Retrying with linear backoff smooths the
//  startup UX.

async function fetchWithRetry(url, opts = {}, attempts = 5, delayMs = 1000) {
    let lastErr = null;
    for (let i = 0; i < attempts; i++) {
        try {
            return await fetch(url, opts);
        } catch (err) {
            lastErr = err;
            if (i < attempts - 1) {
                await new Promise(r => setTimeout(r, delayMs * (i + 1)));
            }
        }
    }
    throw lastErr;
}

async function loadModels() {
    modelSelect.innerHTML = '<option value="">(default)</option>';

    try {
        const res = await fetchWithRetry("/api/llama/all-models");
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        const models = data.models || [];

        // Group by provider so the dropdown has section headers.
        const grouped = { ollama: [], llama_cpp: [] };
        for (const m of models) {
            if (grouped[m.provider]) {
                grouped[m.provider].push(m);
            }
        }

        if (grouped.ollama.length > 0) {
            const grp = document.createElement("optgroup");
            grp.label = `Ollama (${grouped.ollama.length})`;
            for (const m of grouped.ollama) {
                const opt = document.createElement("option");
                opt.value = m.id;
                opt.textContent = `${m.model}  (${m.size_gb} GB)`;
                grp.appendChild(opt);
            }
            modelSelect.appendChild(grp);
        }

        if (grouped.llama_cpp.length > 0) {
            const grp = document.createElement("optgroup");
            grp.label = `Local GGUF (${grouped.llama_cpp.length})`;
            for (const m of grouped.llama_cpp) {
                const opt = document.createElement("option");
                opt.value = m.id;
                opt.textContent = m.loaded
                    ? `✓ ${m.model}  (${m.size_gb} GB, loaded)`
                    : `${m.model}  (${m.size_gb} GB)`;
                grp.appendChild(opt);
            }
            modelSelect.appendChild(grp);
        }

        if (grouped.ollama.length === 0 && grouped.llama_cpp.length === 0) {
            const opt = document.createElement("option");
            opt.value = "";
            opt.textContent = "(no models available)";
            modelSelect.appendChild(opt);
        }

        // Restore the previously selected model.
        const saved = localStorage.getItem(MODEL_STORAGE_KEY);
        if (saved && [...modelSelect.options].some(o => o.value === saved)) {
            modelSelect.value = saved;
        }
    } catch (err) {
        console.warn("Could not load model list:", err);
        const opt = document.createElement("option");
        opt.value = "";
        opt.textContent = "(backend unreachable)";
        modelSelect.appendChild(opt);
    }
}

async function loadGguf(filename) {
    setBusy(true);

        const res = await fetch("/api/llama/runtime/load", {
            method: "POST",

        });
        const data = await res.json().catch(() => ({}));

        if (!res.ok) {
            throw new Error(data.detail || `HTTP ${res.status}`);
        }

        addMessage(`✓ Loaded ${filename}`, "info");

        }
    } catch (err) {
        addMessage(`✗ Load failed: ${err.message}`, "info warn");
    } finally {
        setBusy(false);
    }
}

function connect() {
    const proto = location.protocol === "https:" ? "wss:" : "ws:";
    ws = new WebSocket(`${proto}//${location.host}/ws`);

    ws.onopen = () => {
        statusEl.textContent = "connected";
        statusEl.className = "status online";
    };

    ws.onclose = () => {
        statusEl.textContent = "disconnected";
        statusEl.className = "status offline";
        setTimeout(connect, 2000);
    };

    ws.onerror = () => { if (ws) ws.close(); };

    ws.onmessage = (e) => {
        try {
            handleEvent(JSON.parse(e.data));
        } catch (err) {
            console.error("Bad event:", err, e.data);
        }
    };
}

// ══════════════════════════════════════════════════════════════════════

function handleEvent(ev) {
    resetStallTimer();

    switch (ev.type) {
        case "thinking": {
            if (!thinkingBubble) thinkingBubble = addThinking();
            thinkingBubble.textContent += ev.content || "";
            transcript.scrollTop = transcript.scrollHeight;
            break;
        }

        case "token": {
            thinkingBubble = null;
            if (!streamingBubble) {
                streamingBubble = addMessage("", "agent streaming");
            }
            streamingBubble.content.textContent += ev.content || "";
            transcript.scrollTop = transcript.scrollHeight;
            break;
        }

        case "retry":
            removeStreamingBubble();
            thinkingBubble = null;
            addMessage(`↻ ${ev.message}`, "retry");
            break;

        case "fallback":
            removeStreamingBubble();
            thinkingBubble = null;
            addMessage(`⚡ ${ev.message}`, "fallback");
            break;

        case "info": {
            const isWarn = ev.message &&
                ev.message.toLowerCase().includes("does not support tool");
            addMessage(`ℹ ${ev.message}`, isWarn ? "info warn" : "info");
            break;
        }

        case "tool_call":
            removeStreamingBubble();
            thinkingBubble = null;
            addMessage(`🔧 ${ev.name}(${ev.args})`, "tool");
            break;

        case "tool_result":
            addMessage(`📊 ${ev.result}`, "result");
            break;

        case "final": {
            thinkingBubble = null;
            if (streamingBubble) {
                streamingBubble.div.classList.remove("streaming");
                streamingBubble.content.textContent =
                    ev.content || "(no response)";
                attachActions(
                    streamingBubble.div, ev.content || "", "agent",
                );
                streamingBubble = null;
            } else {
                addMessage(ev.content || "(no response)", "agent");
            }
            if (ev.content) {
                messageLog.push({ role: "assistant", content: ev.content });
            }
            history = ev.messages || [];
            setBusy(false);
            clearStallTimer();
            refreshBusyIndicator();
            input.focus();
            break;
        }

        default:
            console.warn("Unknown event:", ev);
    }
}

function wrapText(text, maxCharsPerLine) {
    const words = String(text).split(/\s+/);
    const lines = [];
    let current = "";

    for (const w of words) {
        if (!current.length) {
            current = w;
        } else if (current.length + 1 + w.length <= maxCharsPerLine) {
            current += " " + w;
        } else {
            lines.push(current);
            current = w;
        }
    }
    if (current.length) lines.push(current);
    return lines;
}

function escapeHtml(s) {
    const div = document.createElement("div");
    div.textContent = String(s);
    return div.innerHTML;
}

function relativeTime(iso) {
    if (!iso) return "";
    try {
        const d = new Date(iso);
        const diff = Date.now() - d.getTime();
        const sec = Math.floor(diff / 1000);
        if (sec < 60) return "just now";
        const min = Math.floor(sec / 60);
        if (min < 60) return `${min}m ago`;
        const hr = Math.floor(min / 60);
        if (hr < 24) return `${hr}h ago`;
        const days = Math.floor(hr / 24);
        if (days < 30) return `${days}d ago`;
        return d.toLocaleDateString();
    } catch {
        return "";
    }
}

function resolveWidgetChoices(widget) {
    if (widget.choices && widget.choices.length > 0) {
        return widget.choices;
    }
    if (widget.dynamic === "ollama.models") {
        const names = state.allModels
            .filter(m => m.provider === "ollama")

function makeNodeClass(t) {
    return class extends LGraphNode {
        constructor() {
            super();

            this.title      = t.title;
            this.color      = t.color;
            this.shape      = LiteGraph.ROUND_SHAPE;
            this.properties = {};
            this.size       = [NODE_WIDTH, 60];

            for (const inp of t.inputs) {
                this.addInput(inp.name, inp.type || "*");
            }
            for (const out of t.outputs) {
                this.addOutput(out.name, out.type || "*");
            }

            for (const w of (t.widgets || [])) {
                this.properties[w.name] = w.default;

                if (w.type === "combo") {
                    const choices = resolveWidgetChoices(w);
                    if (choices && choices.length > 0) {
                        const initial = w.default || choices[0];
                        this.addWidget("combo", w.name, initial, (v) => {
                            this.properties[w.name] =
                                (v === "(default)") ? "" : v;
                        }, { values: choices });
                    } else {
                        this.addWidget("text", w.name,
                            String(w.default ?? ""), (v) => {
                                this.properties[w.name] = v;
                            });
                    }
                } else if (w.type === "number") {
                    this.addWidget("number", w.name, w.default, (v) => {
                        this.properties[w.name] = v;
                    });
                } else if (w.type === "toggle") {
                    this.addWidget("toggle", w.name, !!w.default, (v) => {
                        this.properties[w.name] = v;
                    });
                } else {
                    this.addWidget("text", w.name,
                        String(w.default ?? ""), (v) => {
                            this.properties[w.name] = v;
                        });
                }
            }

            this._typeName   = t.name;
            this._status     = "idle";
            this._outputText = "";

            // Status dot in the top-right corner of the node, plus
            // the current output value drawn under output.text nodes.
            this.onDrawForeground = (ctx) => {
                if (!this.size) return;

                const colors = {
                    idle:    "#555",
                    pending: "#888",
                    running: "#ffcb6c",
                    done:    "#6cff9b",
                    error:   "#ff6c6c",
                };
                ctx.beginPath();
                ctx.arc(this.size[0] - 12, 14, 4, 0, Math.PI * 2);
                ctx.fillStyle = colors[this._status] || "#555";
                ctx.fill();
                ctx.strokeStyle = "#0f1116";
                ctx.lineWidth = 1;
                ctx.stroke();

                if (this._typeName === "output.text" && this._outputText) {
                    ctx.save();
                    ctx.font = "11px ui-monospace, monospace";

                    const lines = wrapText(this._outputText, 32);
                    const lineH = 14;
                    const padTop = 8;
                    const padBot = 8;
                    const boxH = lines.length * lineH + padTop + padBot;
                    const y0 = this.size[1] + 6;

                    ctx.beginPath();
                    if (typeof ctx.roundRect === "function") {
                        ctx.roundRect(0, y0, this.size[0], boxH, 6);
                    } else {
                        ctx.rect(0, y0, this.size[0], boxH);
                    }
                    ctx.fillStyle = "#0f1116";
                    ctx.fill();
                    ctx.strokeStyle = "#6cff9b";
                    ctx.lineWidth = 1;
                    ctx.stroke();

                    ctx.fillStyle = "#6cff9b";
                    for (let i = 0; i < lines.length; i++) {
                        ctx.fillText(
                            lines[i],
                            8,
                            y0 + padTop + (i + 1) * lineH - 3,
                        );
                    }
                    ctx.restore();
                }
            };
        }

        // Execution happens on the Python backend, never client-side.
        onExecute() { /* no-op */ }
    };
}

function graphFromLiteGraph() {
    const lg = state.graph;
    const nodes = [];
    const edges = [];
    let edgeId = 0;

    const idByNode = new Map();

    for (const n of lg._nodes) {
        const backendId = n._backendId || `n${n.id}`;
        n._backendId = backendId;
        idByNode.set(n, backendId);

        const params = {};
        for (const [k, v] of Object.entries(n.properties || {})) {
            params[k] = v;
        }

        // Translate "provider::model" widget values into the two
        // separate params the backend expects.
        if (params.model && params.model.includes("::")) {
            const [provider, model] = params.model.split("::", 2);
            params.model = model;
            if (!params.provider || params.provider === "auto") {
                params.provider = provider;
            }
        }

        nodes.push({
            id: backendId,
            type: n._typeName,
            inputs: {},
            params,
            position: [n.pos[0], n.pos[1]],
            title: n.title,
        });
    }

    for (const n of lg._nodes) {
        if (!n.outputs) continue;

        for (let oi = 0; oi < n.outputs.length; oi++) {
            const out = n.outputs[oi];
            if (!out.links) continue;

            for (const linkId of out.links) {
                const link = lg.links[linkId];
                if (!link) continue;

                const target = lg.getNodeById(link.target_id);
                if (!target) continue;

                const toInput = target.inputs[link.target_slot];
                const toName = toInput
                    ? toInput.name
                    : `in_${link.target_slot}`;

                edges.push({
                    id: `e${++edgeId}`,
                    from_node: idByNode.get(n),
                    from_output: out.name,
                    to_node: idByNode.get(target),
                    to_input: toName,
                });
            }
        }
    }

    return { id: "editor", name: "3olution Graph", nodes, edges };
}

function loadGraphIntoLiteGraph(payload) {
    state.graph.clear();
    state.nodeIdToLiteNode.clear();
    state.liteNodeToId.clear();

    const idByBackendId = new Map();

    for (const n of (payload.nodes || [])) {
        const node = LiteGraph.createNode(n.type);
        if (!node) {
            console.warn("Unknown node type:", n.type);
            continue;
        }

        node.pos = [n.position?.[0] ?? 0, n.position?.[1] ?? 0];
        node.title = n.title || node.title;
        node._backendId = n.id;
        node.properties = { ...(n.params || {}) };

        // Reconstruct the "provider::model" combined value for the
        // dynamic combo widget when a matching option exists.
        if (
            node._typeName === "llm.chat"
            && node.properties.model
            && !node.properties.model.includes("::")
        ) {
            const prov = node.properties.provider || "ollama";
            const reconstructed = `${prov}::${node.properties.model}`;
            if (state.allModels.some(m => m.id === reconstructed)) {
                node.properties.model = reconstructed;
            }
        }

        if (node.widgets) {
            for (const w of node.widgets) {
                if (w.name in node.properties) {
                    w.value = node.properties[w.name] || "(default)";
                }
            }
        }

        state.graph.add(node);
        state.nodeIdToLiteNode.set(n.id, node);
        state.liteNodeToId.set(node, n.id);
        idByBackendId.set(n.id, node);
    }

    for (const e of (payload.edges || [])) {
        const from = idByBackendId.get(e.from_node);
        const to = idByBackendId.get(e.to_node);
        if (!from || !to) continue;

        const fromSlot = (from.outputs || [])
            .findIndex(o => o.name === e.from_output);
        const toSlot = (to.inputs || [])
            .findIndex(i => i.name === e.to_input);

        if (fromSlot < 0 || toSlot < 0) continue;
        from.connect(fromSlot, to, toSlot);
    }

    // Install node-added/removed hooks so new nodes get backend IDs.
    state.graph.onNodeAdded = (node) => {
        if (!node._backendId) {
            node._backendId =
                `n${node.id}_${Math.random().toString(36).slice(2, 6)}`;
        }
        state.nodeIdToLiteNode.set(node._backendId, node);
        state.liteNodeToId.set(node, node._backendId);
    };

    state.graph.onNodeRemoved = (node) => {
        if (node._backendId) {
            state.nodeIdToLiteNode.delete(node._backendId);
            state.liteNodeToId.delete(node);
        }
    };
}

function renderEventToLog(ev) {
    switch (ev.type) {
        case "graph_start":
            logLine(
                `▶ Graph start (${(ev.order || []).length} nodes)`,
                "log-meta",
            );
            break;

        case "node_start":
            // Too noisy for the log; the status dots on the canvas
            // already show which node is running.
            break;

        case "node_done": {
            const node = state.nodeIdToLiteNode.get(ev.node);
            const title = node ? node.title : ev.node;
            logLine(`✔ ${title}`, "log-ok");
            for (const [k, v] of Object.entries(ev.outputs || {})) {
                logLine(`   ${k}: ${v}`, "log-dim");
            }
            break;
        }

        case "node_error":
            logLine(`✘ ${ev.node}: ${ev.error}`, "log-err");
            break;

        case "retry":
            logLine(`↻ ${ev.message}`, "log-retry");
            break;

        case "fallback":
            logLine(`⚡ ${ev.message}`, "log-fallback");
            break;

        case "info":
            logLine(`ℹ ${ev.message}`, "log-info");
            break;

        case "thinking":
            logLine(`💭 ${ev.content}`, "log-thinking");
            break;

        case "token":
            // The graph editor does not render tokens; they are chat-only.
            break;

        case "graph_done": {
            logLine("── graph complete ──", "log-ok");
            const outputs = ev.outputs || {};
            const results = [];

            for (const [nid, outs] of Object.entries(outputs)) {
                const n = state.nodeIdToLiteNode.get(nid);
                if (n && n._typeName === "output.text" && outs.result) {
                    logLine(`▶ ${n.title}: ${outs.result}`, "log-result");
                    results.push({
                        title: n.title || "Result",
                        text: String(outs.result),
                    });
                }
            }

            if (results.length === 1) {
                showResultBar(results[0].text);
            } else if (results.length > 1) {
                showResultBar(
                    results.map(r => `▶ ${r.title}\n${r.text}`).join("\n\n")
                );
            }
            break;
        }

        case "graph_error":
            logLine(`graph error: ${ev.error}`, "log-err");
            showResultBar(`Error: ${ev.error}`);
            break;

        case "run_saved":
            logLine(`💾 run saved: ${ev.run_id}`, "log-meta");
            break;

        default:
            logLine(`[event] ${ev.type}`, "log-dim");
            break;
    }
}

//  Execution
// ══════════════════════════════════════════════════════════════════════

function run() {
    if (state.running) return;

    state.running = true;
    document.getElementById("btn-run").disabled = true;
    setStatus("connecting…", "running");
    clearLog();
    hideResultBar();
    state.selectedRunId = null;

    for (const n of state.graph._nodes) {
        n._status = "idle";
        n._outputText = "";
    }
    state.canvas.setDirty(true);

    const proto = location.protocol === "https:" ? "wss:" : "ws:";
    const ws = new WebSocket(`${proto}//${location.host}/ws/graph`);
    state.ws = ws;

    ws.onopen = () => {
        setStatus("running", "running");
        ws.send(JSON.stringify(graphFromLiteGraph()));
    };

    ws.onmessage = (e) => {
        let ev;
        try { ev = JSON.parse(e.data); } catch { return; }
        handleLiveEvent(ev);
    };

    ws.onclose = () => {
        state.running = false;
        document.getElementById("btn-run").disabled = false;
        if (statusEl.textContent === "running") setStatus("idle");
        state.ws = null;
    };

    ws.onerror = () => setStatus("error", "error");
}

function handleLiveEvent(ev) {
    // Update node status dots first.
    switch (ev.type) {
        case "graph_start":
            for (const id of ev.order) {
                const n = state.nodeIdToLiteNode.get(id);
                if (n) n._status = "pending";
            }
            state.canvas.setDirty(true);
            break;

        case "node_start": {
            const n = state.nodeIdToLiteNode.get(ev.node);
            if (n) n._status = "running";
            state.canvas.setDirty(true);
            break;
        }

        case "node_done": {
            const n = state.nodeIdToLiteNode.get(ev.node);
            if (n) n._status = "done";
            if (n && n._typeName === "output.text") {
                const outs = ev.outputs || {};
                if (outs.result) n._outputText = String(outs.result);
            }
            state.canvas.setDirty(true);
            break;
        }

        case "node_error": {
            const n = state.nodeIdToLiteNode.get(ev.node);
            if (n) n._status = "error";
            state.canvas.setDirty(true);
            break;
        }

        case "graph_done":
            setStatus("done", "done");
            break;

        case "graph_error":
            setStatus("error", "error");
            break;

        case "run_saved":
            state.selectedRunId = ev.run_id;
            loadHistory().then(() => highlightSelectedRun());
            break;
    }

    // Then render the textual log entry.
    renderEventToLog(ev);
}

async function loadHistory() {
    try {
        const res = await fetch(`${BACKEND}/api/graph/runs?limit=50`);
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const data = await res.json();
        state.runs = data.runs || [];
        renderHistoryList();
    } catch (err) {
        console.warn("Could not load history:", err);
        state.runs = [];
        renderHistoryList();
    }
}

function renderHistoryList() {
    if (!state.runs.length) {
        historyList.innerHTML = `
            <div class="history-empty">No runs yet.</div>`;
        return;
    }

    historyList.innerHTML = "";

    for (const run of state.runs) {
        const item = document.createElement("div");
        item.className = "history-item";
        item.dataset.runId = run.id;

        const statusClass = run.status === "error" ? "err" : "ok";
        const time = relativeTime(run.finished_at);
        const preview = run.final_text_preview || "(no output)";

        item.innerHTML = `
            <div class="history-item-header">
                <span class="history-dot ${statusClass}"></span>
                <span class="history-name">${escapeHtml(run.graph_name)}</span>
                <button class="history-delete" title="Delete this run">×</button>
                <span class="history-time">${escapeHtml(time)}</span>
            </div>
            <div class="history-meta">
                ${run.node_count} nodes · ${run.event_count} events
            </div>
            <div class="history-preview">${escapeHtml(preview)}</div>
        `;

        item.addEventListener("click", (e) => {
            if (e.target.classList.contains("history-delete")) return;
            replayRun(run.id);
        });

        item.querySelector(".history-delete").addEventListener(
            "click",
            (e) => {
                e.stopPropagation();
                deleteRun(run.id);
            },
        );

        historyList.appendChild(item);
    }

    highlightSelectedRun();
}

function highlightSelectedRun() {
    for (const el of historyList.querySelectorAll(".history-item")) {
        if (el.dataset.runId === state.selectedRunId) {
            el.classList.add("selected");
        } else {
            el.classList.remove("selected");
        }
    }
}

async function replayRun(runId) {
    try {
        const res = await fetch(
            `${BACKEND}/api/graph/runs/${encodeURIComponent(runId)}`
        );
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        const run = await res.json();

        state.selectedRunId = runId;
        highlightSelectedRun();

        clearLog();
        hideResultBar();

        logLine(
            `══ Replaying run from ` +
            `${new Date(run.finished_at).toLocaleString()} ══`,
            "log-meta",
        );

        for (const n of state.graph._nodes) {
            n._outputText = "";
            n._status = "idle";
        }
        state.canvas.setDirty(true);

        for (const ev of (run.events || [])) {
            if (ev.type === "node_done" && ev.outputs) {
                const n = state.nodeIdToLiteNode.get(ev.node);
                if (n && n._typeName === "output.text" && ev.outputs.result) {
                    n._outputText = String(ev.outputs.result);
                    n._status = "done";
                }
            }
            renderEventToLog(ev);
        }

        state.canvas.setDirty(true);

        if (run.final_text) {
            showResultBar(run.final_text);
        } else {
            showResultBar("(no output.text node produced a result)");
        }
        setStatus("replayed", "done");
    } catch (err) {
        console.warn("Could not replay run:", err);
        logLine(`Failed to load run: ${err.message}`, "log-err");
    }
}

async function deleteRun(runId) {
    if (!confirm("Delete this run from history?")) return;

    try {
        const res = await fetch(
            `${BACKEND}/api/graph/runs/${encodeURIComponent(runId)}`,
            { method: "DELETE" },
        );
        if (!res.ok) {
            const err = await res.json().catch(() => ({}));
            throw new Error(err.detail || `HTTP ${res.status}`);
        }
        if (state.selectedRunId === runId) {
            state.selectedRunId = null;
        }
        await loadHistory();
    } catch (err) {
        alert(`Delete failed: ${err.message}`);
    }
}

async function clearHistory() {
    if (!confirm("Delete ALL stored runs? This cannot be undone.")) return;

    try {
        const res = await fetch(`${BACKEND}/api/graph/runs/all`, {
            method: "DELETE",

        if (!res.ok) {
            const err = await res.json().catch(() => ({}));

        await loadHistory();
        clearLog();
        hideResultBar();
        logLine("History cleared.", "log-meta");

    }
}

    }

function save() {
    const payload = graphFromLiteGraph();
    const blob = new Blob([JSON.stringify(payload, null, 2)], {

    });
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = "3olution-graph.json";
    a.click();
    URL.revokeObjectURL(url);
}

function load() {
    const input = document.createElement("input");
    input.type = "file";
    input.accept = "application/json";
    input.onchange = () => {
        const file = input.files[0];
        if (!file) return;

        const reader = new FileReader();
        reader.onload = () => {
            try {
                const payload = JSON.parse(reader.result);
                loadGraphIntoLiteGraph(payload);
                state.canvas.setDirty(true);
            } catch (err) {
                alert("Invalid graph file: " + err.message);
            }
        };
        reader.readAsText(file);
    };
    input.click();
}

function clearGraph() {
    if (!confirm("Clear the entire graph?")) return;
    state.graph.clear();
    state.nodeIdToLiteNode.clear();
    state.liteNodeToId.clear();
    hideResultBar();
    state.canvas.setDirty(true);
}

/**
 * Fetch an SSE endpoint via fetch() and dispatch each parsed JSON
 * frame to a callback. Resolves when the stream ends.
 */
async function streamSSE(url, options, onEvent) {
    const res = await fetch(url, options);
    if (!res.ok) {
        let detail = `HTTP ${res.status}`;
        try {
            const j = await res.json();
            if (j.detail) detail = j.detail;
        } catch { /* ignore */ }
        throw new Error(detail);
    }

    const reader  = res.body.getReader();
    const decoder = new TextDecoder();
    let buffer = "";
    let done = false;

    while (!done) {
        const chunk = await reader.read();
        if (chunk.done) break;

        buffer += decoder.decode(chunk.value, { stream: true });
        const frames = buffer.split("\n\n");
        buffer = frames.pop();

        for (const frame of frames) {
            for (const line of frame.split("\n")) {
                if (!line.startsWith("data: ")) continue;
                const payload = line.slice(6);
                if (payload === "[DONE]") { done = true; continue; }
                try { onEvent(JSON.parse(payload)); }
                catch (err) { console.warn("Bad SSE frame:", payload, err); }
            }
        }
    }
}

function formatDate(iso) {
    if (!iso) return "—";
    try {
        const d = new Date(iso);
        const diff = Date.now() - d.getTime();
        const days = Math.floor(diff / 86400000);
        if (days === 0) return "today";
        if (days === 1) return "yesterday";
        if (days < 30) return `${days} days ago`;
        return d.toLocaleDateString();
    } catch {
        return iso;
    }
}

            `${status}  ${cMB} / ${tMB} MB (${pct.toFixed(1)}%)`;
    } else {
        pullStatus.textContent = status;
    }
}

async function pullModel(name) {
    pullProgress.classList.remove("hidden");
    pullBar.style.width = "0%";
    pullBar.style.background = "linear-gradient(90deg, #2563eb, #7c3aed)";
    pullStatus.textContent = `Pulling ${name}…`;

    try {
        await streamSSE(
            "/api/ollama/models/pull",
            {
                method: "POST",
                headers: { "Content-Type": "application/json" },
                body: JSON.stringify({ name }),
            },
            (event) => {
                updatePullProgress(event);
                if (event.status === "success") {
                    pullBar.style.width = "100%";
                    pullStatus.textContent = `✓ ${name} ready`;
                }
            },
        );

        await loadModels();
        await loadStatus();
    } catch (err) {
        pullStatus.textContent = `Error: ${err.message}`;
        pullBar.style.background = "#ef4444";
    }
}

    } finally {
        pullBtn.disabled = false;

    }
