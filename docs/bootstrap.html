Bootstrap Runtime

Self-contained portable runtime for the 3olution Agent Graph backend. Downloads and installs portable Python, PHP (CGI + CLI), and the SQLite CLI into runtime/ so the project runs without a system-wide Python, PHP, or SQLite installation. Handles Windows quirks (missing php.ini, VS16 vs VS17 builds) automatically.

Portable Runtime Bootstrap

The bootstrap/ folder contains a single script, setup.py, whose job is to make the 3olution Agent Graph backend runnable on a machine that has nothing installed except a working Python interpreter (3.8+). After the script finishes, the project has:

  • A private Python 3.12 interpreter under runtime/python/,
  • A private PHP runtime (CGI + CLI) under runtime/php/,
  • A private SQLite CLI under runtime/sqlite/,
  • All Python dependencies installed into that private Python,
  • The LiteGraph vendor files fetched into web/vendor/,
  • A manifest file at runtime/runtime.env describing what was installed.
Why a portable runtime? It removes the entire class of "it works on my machine" problems. Every install — Windows, macOS, Linux — has the same Python version, the same PHP build, and the same SQLite CLI. Nothing leaks in from the host system.

What bootstrap does not do

  • It does not install the MCP server. That is a separate mcp_server package, run from the same portable Python.
  • It does not download GGUF models. Those go into models/ and are managed by the settings page.
  • It does not install llama-cpp-python. That is done at runtime through the settings page, because the correct wheel depends on the host's CUDA version.
  • It does not touch the host's system Python, PATH, or registry.

ScenarioCommand

Version pins

The script pins specific versions so builds are reproducible:

ComponentVersionSource

The Windows installer additionally tries vs17 before vs16, and the releases folder before releases/archives.

Install pipeline

main() runs six stages in a fixed order. Each stage logs its own section header, and the whole run ends with a summary table. A failure in one stage does not abort the others unless a later stage depends on it — for example, pip cannot install into a Python that was never unpacked.

Stage 1 — Python

install_python(plat, force)
  1. If runtime/python/python.exe (or bin/python3) already exists and --force is not set, skip.
  2. Download cpython-3.12.11+20250712-<triple>-install_only_stripped.tar.gz from the astral-sh/python-build-standalone GitHub releases.
  3. Extract the archive into a temp directory, then move the single top-level folder into runtime/python/.
  4. Verify by running python --version. On failure, remove the folder and return False.

The platform triple is chosen by detect_platform():

OSArchTriple
Windowsx86_64x86_64-pc-windows-msvc
Windowsarm64aarch64-pc-windows-msvc
Linuxx86_64x86_64-unknown-linux-gnu
Linuxaarch64aarch64-unknown-linux-gnu
macOSx86_64x86_64-apple-darwin
macOSarm64aarch64-apple-darwin

Stage 2 — PHP

The installer branches on plat["is_windows"]:

Unix path (Linux / macOS)

_install_php_unix(plat, force)

Uses the static-php-cli bulk builds from dl.static-php.dev. Each candidate version produces a single tarball like: 

php-8.4.20-cli-linux-x86_64.tar.gz

Inside is a statically-linked php binary plus a php-cgi symlink (or a sibling binary, depending on the build). Both are moved into runtime/php/ and marked executable.

Windows path

_install_php_windows(plat, force)

Downloads the official Windows PHP ZIP from windows.php.net. This is the only distribution that ships php-cgi.exe alongside php.exe. See the dedicated PHP on Windows section for the full detail.

Stage 3 — SQLite CLI

install_sqlite(plat, force)

Downloads sqlite-tools-<platform>-3460000.zip from sqlite.org. The archive contains sqlite3.exe, sqldiff.exe, and sqlite3_analyzer.exe. All three land in runtime/sqlite/.

Platform mapping:

OSsqlite_platform
Windows x64win-x64
Windows arm64win-arm64
Linux x64linux-x64
macOS x64osx-x64

Stage 4 — Python dependencies

install_python_deps(plat)
  1. Ensures pip is available (ensurepip --upgrade if not).
  2. Upgrades pip itself (non-fatal if it fails).
  3. Runs pip install -r requirements.txt using the private Python.

Because the private Python has no system site-packages, every dependency must be installed here — including fastapi, uvicorn, openai, mcp, httpx, and loguru.

Stage 5 — LiteGraph vendor files

download_vendor(plat)

Runs scripts/download_vendor.py, which fetches litegraph.min.js and litegraph.css into web/vendor/. These are the only external assets the frontend needs; everything else ships from CDN at runtime (with local fallback).

Vendor files are optional. If the download fails, the graph editor loads LiteGraph from jsDelivr instead. The backend always starts.

Stage 6 — Manifest

write_runtime_env(plat)

Writes runtime/runtime.env, a shell-sourceable file that records exactly which binaries were installed and where. Tools like start.sh and start.bat source this file to locate the private Python and PHP. 

RUNTIME_PLATFORM=windows
RUNTIME_ARCH=x86_64
RUNTIME_PYTHON_VERSION=3.12.11
RUNTIME_PHP_VERSION=8.4.15
RUNTIME_SQLITE_VERSION=3460000

RUNTIME_PYTHON=C:\...\runtime\python\python.exe
RUNTIME_PHP_CLI=C:\...\runtime\php\php.exe
RUNTIME_PHP_CGI=C:\...\runtime\php\php-cgi.exe
RUNTIME_SQLITE=C:\...\runtime\sqlite\sqlite3.exe

Command-line reference

python bootstrap/setup.py [options]

Flags

FlagEffect
--force Re-download and reinstall every component, even if a working copy already exists. Cached archives are also re-fetched. Use after a corrupt install.
--skip-python Do not install portable Python. Useful when only PHP or SQLite needs updating.
--skip-php Do not install PHP. The /php/ notes app will return a 500 error with a helpful message.
--skip-sqlite Do not install the SQLite CLI. The backend does not need it (Python has its own sqlite3 module) — this is only for manual database inspection.
--skip-deps Do not run pip install -r requirements.txt. Use when you have already installed deps manually.
--skip-vendor Do not download LiteGraph. The frontend will load from jsDelivr instead.
--check Do not install anything. Just report the current state of runtime/ and exit. Exit code 0 means everything needed is present.
--verbose Print a full Python traceback if an unexpected error occurs. Without this, only a one-line error message is shown.

Common recipes

Fix a missing php.ini

python bootstrap/setup.py --force --skip-python --skip-sqlite --skip-deps --skip-vendor

Re-runs the PHP installer only. On Windows this re-extracts the official ZIP and rewrites runtime/php/php.ini. Fast (about 30 seconds) because nothing else is touched.

Rebuild the Python venv from scratch

python bootstrap/setup.py --force --skip-php --skip-sqlite --skip-vendor

Re-downloads Python and reinstalls every pip dependency. Use when a package is corrupted or the interpreter itself misbehaves.

CI / unattended install

python bootstrap/setup.py --skip-vendor

On a CI runner with no outbound access to jsDelivr, skip the vendor download. The backend serves the graph editor's fallback CDN link instead.

Diagnostics

python bootstrap/setup.py --check

Prints a report of every expected binary with its path, size, and whether it verifies. Useful for a bug report — paste the output.

Environment variables

VariableEffect
NO_COLOR=1 Disable ANSI colour in the console output. The script honours the no-color.org convention. Useful when piping output to a file.

PHP on Windows — the full story

This is the messiest part of the bootstrap, so it gets its own section. If you ever need to debug a /php/ route that returns blank output or a 500, start here.

The problem

Unix static-php-cli builds are clean: one tarball, one static binary, zero dependencies. There is no equivalent for Windows. The static-php-cli project publishes a Windows ZIP, but it only contains the CLI SAPI — php.exe. The backend needs CGI SAPI — php-cgi.exe — because that is the only mode that speaks the CGI protocol the PHP notes app depends on.

Without php-cgi.exe, the /php/ app cannot run. The backend's php_server.py will still start, but every request to /php/* returns a 500 with "The resolved PHP binary is a CLI build, not a CGI build".

The solution

Use the official Windows PHP build from windows.php.net. That ZIP is larger (30+ MB vs the ~6 MB static-php-cli Windows build) and contains many DLLs, but it ships both SAPIs and every extension DLL the notes app needs.

What the ZIP contains:

php-8.4.15-Win32-vs17-x64/
    php.exe              ← CLI SAPI
    php-cgi.exe          ← CGI SAPI  (this is why we use this ZIP)
    php8ts.dll           ← the PHP engine
    php8ts.pdb
    ext/                 ← extension DLLs
        php_pdo_sqlite.dll
        php_sqlite3.dll
        php_mbstring.dll
        php_openssl.dll
        php_curl.dll
        ... (60+ more)
    libcrypto-3-x64.dll
    libssl-3-x64.dll
    ... every runtime DLL PHP needs
    php.ini-development  ← sample, but NOT loaded by default
    php.ini-production   ← sample, but NOT loaded by default
Notice what's missing: a real php.ini. The ZIP ships two samples but no actual config file. PHP will not load either one automatically.

The php.ini trap

Without a php.ini, PHP loads with every extension disabled. The notes app calls new PDO('sqlite:...'), which raises could not find driver — a confusing error because the SQLite library is right there in the ZIP.

The bootstrap writes a minimal php.ini into runtime/php/ after extraction: 

extension_dir = "ext"

extension=pdo_sqlite
extension=sqlite3
extension=mbstring
extension=openssl

display_errors = On
error_reporting = E_ALL

date.timezone = UTC

Each extension is required by something in the notes app:

ExtensionRequired by
pdo_sqliteThe PDO connection in db.php
sqlite3Companion to pdo_sqlite; some helper functions use it directly
mbstringmb_strlen() and mb_substr() in index.php
opensslPassword hashing helpers and any future HTTPS calls

The vs16 / vs17 question

Microsoft's C++ runtime has two major versions in circulation:

  • VS16 — Visual Studio 2019 toolchain. Runs on Windows 8.1+.
  • VS17 — Visual Studio 2022 toolchain. Requires Windows 10+.

PHP 8.4 and later are VS17-only. PHP 8.3 and earlier are available in both. The bootstrap picks the best match based on the version string: 

def _windows_vs_variants(version):
    major, minor = parse(version)
    if major > 8 or (major == 8 and minor >= 4):
        return ["vs17", "vs16"]
    return ["vs16", "vs17"]

Each variant is tried in order. If vs17 is missing (say, because the runner is on Windows 8.1), the installer silently falls through to vs16.

The releases vs releases/archives question

windows.php.net keeps the current point release in downloads/releases/ and older ones in downloads/releases/archives/. When a new PHP 8.4.x drops, the previous version is moved to archives — and any pinned URL breaks.

The bootstrap tries releases/ first (fast, always current) then releases/archives/ (fallback for the pinned versions).

Full fallback matrix

For a Windows install, the script tries up to 8 versions × 2 VS variants × 2 folders = 32 combinations before giving up. In practice the very first combination (8.4.15/vs17/releases) succeeds. 

PHP_WINDOWS_VERSION_CANDIDATES = [
    "8.4.15", "8.4.14",
    "8.3.33", "8.3.32", "8.3.31", "8.3.30",
    "8.2.30", "8.2.29",
]

Verifying the install

After extraction, the script runs php-cgi.exe -v and checks for a zero exit code. If the binary is missing a DLL, Windows usually pops a dialog and the process exits non-zero. That is caught here and reported.

To check by hand:

> runtime\php\php-cgi.exe -v
PHP 8.4.15 (cgi-fcgi) (built: Jan 14 2026 10:32:41)
Copyright (c) The PHP Group
Zend Engine v4.4.15, Copyright (c) Zend Technologies

> runtime\php\php.exe -m
[PHP Modules]
...
mbstring
openssl
pdo_sqlite
sqlite3
...

If pdo_sqlite is missing from -m, the php.ini was not loaded. Check that runtime/php/php.ini exists and contains the four extension= lines.

Quick fix for a broken php.ini: 
python bootstrap/setup.py --force --skip-python --skip-sqlite --skip-deps --skip-vendor
Re-extracts the PHP ZIP and writes a fresh php.ini. Takes 30 seconds and does not touch anything else.

Why not ship a prebuilt PHP?

We could put a PHP ZIP in the repo, but:

  • GitHub has a 100 MB per-file limit. The PHP ZIP is 30 MB, ×2 for both VS variants = 60 MB. Doable, but the repo bloats fast.
  • Antivirus software flags extracted PHP binaries from unknown sources. Downloading from windows.php.net keeps the provenance clear.
  • Microsoft's Visual C++ runtime is a prerequisite. The installer can detect a missing runtime and suggest the fix, but a bundled binary would just crash.

The manifest file

runtime/runtime.env is a shell-sourceable file with one KEY=VALUE per line. It exists so that start.sh and start.bat do not have to hard-code paths: 

# On Unix
source runtime/runtime.env
"$RUNTIME_PYTHON" -m uvicorn backend.main:app

# On Windows
for /f "usebackq tokens=1,* delims==" %%a in ("runtime\runtime.env") do (
    if not "%%a"=="" if not "%%a:~0,1%"=="#" set "%%a=%%b"
)
"%RUNTIME_PYTHON%" -m uvicorn backend.main:app

The manifest is written last, after every other stage has completed. If bootstrap fails halfway through, the manifest is absent — which the launcher scripts detect and report as "run bootstrap first".

Cross-platform layout differences

Windows

runtime/python/python.exe
runtime/php/php.exe
runtime/php/php-cgi.exe
runtime/sqlite/sqlite3.exe

Linux / macOS

runtime/python/bin/python3
runtime/php/php
runtime/php/php-cgi

The helper functions python_binary(), php_cli_binary(), php_cgi_binary(), and sqlite_binary() encapsulate this difference so no other code needs to care.

Troubleshooting

Download fails with HTTP 403 or 404

The pinned version was probably retired. Check the version candidate lists at the top of setup.py and add a newer version. For PHP Windows, the URL structure is: 

https://windows.php.net/downloads/releases/php-8.4.15-Win32-vs17-x64.zip

Browse windows.php.net/download/ to confirm which versions are currently listed.

"Archive is too small after download"

Almost always a captive portal or corporate proxy returning an HTML error page instead of the actual file. Verify with: 

> curl -I https://windows.php.net/downloads/releases/php-8.4.15-Win32-vs17-x64.zip
HTTP/1.1 200 OK
Content-Length: 32618504
Content-Type: application/zip

If Content-Type is text/html, you are behind a login wall. Configure your proxy or use a different network.

Antivirus quarantines php-cgi.exe

Some consumer AV products flag freshly-extracted PHP binaries from windows.php.net. This is a false positive — the official ZIP is signed and the binaries carry the PHP project's signature.

Options:

  • Add <project>\runtime\php\ to the AV exclusion list.
  • Use Windows Defender, which does not false-positive on these.
  • Install PHP system-wide (via XAMPP or Chocolatey) and set AGENT_PHP_BINARY in .env to point at it.

"Could not find driver" from the notes app

The php.ini is missing or the extensions are not enabled. Check: 

> runtime\php\php.exe -m
[PHP Modules]
...
pdo_sqlite
sqlite3
...

If those two lines are absent, the php.ini is not being loaded. Confirm it exists: 

> dir runtime\php\php.ini

If it is missing, run the PHP-only reinstall: 

python bootstrap/setup.py --force --skip-python --skip-sqlite --skip-deps --skip-vendor

"Unsupported CPU: <arch>"

The bootstrap only knows x86_64 and aarch64/arm64. If you are on 32-bit x86 or an exotic architecture, download the runtimes manually and set AGENT_PHP_BINARY plus a suitable system Python.

pip install fails on a specific package

Some packages need a C compiler. On Windows, install the Microsoft C++ Build Tools and re-run. On Linux, install build-essential and python3-dev.

A faster alternative: install wheels from a pre-built index. Add --only-binary :all: to the pip line temporarily to see which packages lack wheels.

"Runtime is incomplete" from --check

--check returns exit code 1 when any required component is missing. See the exact line marked [error] in the output:

MessageFix
Python: missingRun full bootstrap without --skip-python.
Python: <detail>The binary exists but does not run. Delete runtime/python/ and re-run.
PHP CGI: missingRun bootstrap without --skip-php.
php.ini: missingRun the PHP-only reinstall (above).
SQLite CLI: missingOptional. Run without --skip-sqlite if you want it.

Bootstrap crashes with a Python traceback

Re-run with --verbose to see the full stack: 

python bootstrap/setup.py --verbose

Common causes:

  • Running under a Python older than 3.8 (exit code 2, clear message).
  • A read-only runtime/ directory (check permissions).
  • Disk full during extraction.
  • Antivirus blocking a .exe from being written.

Cache corruption

If a download completed but the extracted binary is broken, the cached archive is the suspect. Delete it and force a fresh download: 

> rmdir /s /q runtime\_downloads
> python bootstrap/setup.py --force

On Unix: 

$ rm -rf runtime/_downloads
$ python bootstrap/setup.py --force

Still stuck?

Capture the full output of --check and setup.py --verbose, and include:

  • Your OS and version (winver, uname -a)
  • The Python version running the bootstrap (python --version)
  • Any antivirus or corporate proxy in the path

def _try_enable_windows_ansi() -> bool:
    if sys.platform != "win32":
        return True
    try:
        import ctypes
        k32 = ctypes.windll.kernel32
        h = k32.GetStdHandle(-11)
        if h in (0, -1):
            return False
        mode = ctypes.c_ulong()
        if not k32.GetConsoleMode(h, ctypes.byref(mode)):
            return False
        if not k32.SetConsoleMode(h, mode.value | 0x0004):
            return False
        return True
    except Exception:
        return False

class Log:
    @staticmethod
    def _c(code: str, text: str) -> str:
        return f"\033[{code}m{text}\033[0m" if _USE_COLOR else text

    @staticmethod
    def info(m: str)  -> None: print(Log._c("36", "[info] ") + m)
    @staticmethod
    def ok(m: str)    -> None: print(Log._c("32", "[ok]   ") + m)
    @staticmethod
    def warn(m: str)  -> None: print(Log._c("33", "[warn] ") + m)
    @staticmethod
    def error(m: str) -> None: print(Log._c("31", "[error] ") + m, file=sys.stderr)

    @staticmethod
    def title(m: str) -> None:
        bar = "=" * 66
        print()
        print(Log._c("36", bar))
        print(Log._c("36", "  " + m))
        print(Log._c("36", bar))

    @staticmethod
    def banner() -> None:
        print()
        print(Log._c("36", "=" * 66))
        print(Log._c("36", "  3olution Agent Graph - Portable Runtime Bootstrap"))
        print(Log._c("36", "  https://3olution.com"))
        print(Log._c("36", "=" * 66))
        print()

def detect_platform() -> dict[str, Any]:
    system_raw = platform.system().lower()
    machine_raw = platform.machine().lower()

    if machine_raw in ("x86_64", "amd64"):
        arch = "x86_64"
    elif machine_raw in ("arm64", "aarch64"):
        arch = "aarch64"
    else:
        raise SystemExit(f"Unsupported CPU: {machine_raw}")

    if system_raw == "windows":
        return {
            "system": "windows", "arch": arch,
            "python_triple": f"{arch}-pc-windows-msvc",
            "php_os": "windows",
            "php_arch": "x64" if arch == "x86_64" else "arm64",
            "sqlite_platform": f"win-{'x64' if arch == 'x86_64' else 'arm64'}",
            "exe_suffix": ".exe", "is_windows": True,
        }
    if system_raw == "linux":
        return {
            "system": "linux", "arch": arch,
            "python_triple": f"{arch}-unknown-linux-gnu",
            "php_os": "linux", "php_arch": arch,
            "sqlite_platform": "linux-x64",
            "exe_suffix": "", "is_windows": False,
        }
    if system_raw == "darwin":
        return {
            "system": "macos", "arch": arch,
            "python_triple": f"{arch}-apple-darwin",
            "php_os": "macos", "php_arch": arch,
            "sqlite_platform": "osx-x64",
            "exe_suffix": "", "is_windows": False,
        }
    raise SystemExit(f"Unsupported OS: {system_raw}")

def _human_bytes(n: int) -> str:
    n_f = float(n)
    for unit in ("B", "KB", "MB", "GB"):
        if abs(n_f) < 1024:
            return f"{n_f:.1f} {unit}"
        n_f /= 1024
    return f"{n_f:.1f} TB"


def _render_progress(d, total, start, final=False):
    elapsed = max(time.monotonic() - start, 0.001)
    speed = d / elapsed
    size = _human_bytes(d)
    speed_s = _human_bytes(int(speed)) + "/s"
    if total > 0:
        pct = d / total * 100
        filled = int(24 * pct / 100)
        bar = "#" * filled + "-" * (24 - filled)
        line = f"    [{bar}] {pct:5.1f}%   {size} / {_human_bytes(total)}   {speed_s}"
    else:
        line = f"    {size}   {speed_s}"
    end = "\n" if final else "\r"
    print(line.ljust(78), end=end, flush=True)


def _download_one(url: str, dest: Path) -> None:
    dest.parent.mkdir(parents=True, exist_ok=True)
    tmp = dest.with_suffix(dest.suffix + ".part")
    req = urllib.request.Request(
        url, headers={"User-Agent": "3olution-setup/1.0 (+https://3olution.com)"},
    )
    with urllib.request.urlopen(req, timeout=DOWNLOAD_TIMEOUT) as response:
        total = int(response.headers.get("Content-Length", "0"))
        downloaded = 0
        start = time.monotonic()
        last_render = start
        with open(tmp, "wb") as f:
            while True:
                chunk = response.read(64 * 1024)
                if not chunk:
                    break
                f.write(chunk)
                downloaded += len(chunk)
                now = time.monotonic()
                if now - last_render > 0.1:
                    _render_progress(downloaded, total, start)
                    last_render = now
        _render_progress(downloaded, total, start, final=True)
    tmp.replace(dest)


def download(url, dest, *, force=False, expected_min_size=0, label="file") -> Path:
    if dest.exists() and not force:
        size = dest.stat().st_size
        if size >= expected_min_size:
            Log.ok(f"{label} already cached ({_human_bytes(size)})")
            return dest
        Log.warn(f"{label} cached but small - re-downloading")
    Log.info(f"Downloading {label}")
    print(f"    {url}")
    try:
        _download_one(url, dest)
    except urllib.error.HTTPError as e:
        raise RuntimeError(f"HTTP {e.code} while downloading {label}") from e
    except urllib.error.URLError as e:
        raise RuntimeError(f"Network error while downloading {label}: {e}") from e
    except TimeoutError as e:
        raise RuntimeError(f"Timeout downloading {label}") from e
    if dest.stat().st_size < expected_min_size:
        try: dest.unlink()
        except OSError: pass
        raise RuntimeError(f"{label} is too small after download")
    return dest

#  Archive helpers

def _is_within(base: Path, target: Path) -> bool:
    try:
        target.resolve().relative_to(base.resolve())
        return True
    except ValueError:
        return False


def _safe_extract_tar(tf, target):
    target = target.resolve()
    for m in tf.getmembers():
        if not _is_within(target, (target / m.name)):
            raise RuntimeError(f"Unsafe path: {m.name}")
    if sys.version_info >= (3, 12):
        tf.extractall(target, filter="data")
    else:
        tf.extractall(target)


def _safe_extract_zip(zf, target):
    target = target.resolve()
    for m in zf.namelist():
        if not _is_within(target, (target / m)):
            raise RuntimeError(f"Unsafe path: {m}")
    zf.extractall(target)


def _extract_to_temp(archive: Path, fmt: str) -> Path:
    tmp = Path(tempfile.mkdtemp(prefix="3olution-setup-"))
    try:
        if fmt in ("tar.gz", "tar.xz"):
            mode = "r:gz" if fmt == "tar.gz" else "r:xz"
            with tarfile.open(archive, mode) as tf:
                _safe_extract_tar(tf, tmp)
        elif fmt == "zip":
            with zipfile.ZipFile(archive, "r") as zf:
                _safe_extract_zip(zf, tmp)
        else:
            raise ValueError(f"Unknown format: {fmt}")
    except Exception:
        shutil.rmtree(tmp, ignore_errors=True)
        raise
    return tmp


def _find_extract_root(tmp: Path) -> Path:
    entries = list(tmp.iterdir())
    if len(entries) == 1 and entries[0].is_dir():
        return entries[0]
    return tmp

def _verify_python(exe: Path):
    try:
        r = subprocess.run([str(exe), "--version"], capture_output=True,
                           text=True, timeout=15)
        if r.returncode == 0:
            return True, (r.stdout or r.stderr).strip()
        return False, f"exit code {r.returncode}"
    except Exception as e:
        return False, str(e)


def _verify_php_cgi(exe: Path):
    try:
        r = subprocess.run([str(exe), "-v"], capture_output=True,
                           text=True, timeout=15)
        if r.returncode == 0:
            output = (r.stdout or r.stderr).strip()
            first_line = output.splitlines()[0] if output else ""
            return True, first_line
        return False, f"exit code {r.returncode}"
    except Exception as e:
        return False, str(e)

def _write_php_ini(target_dir: Path) -> bool:

def install_python(plat, force):
    Log.title(f"Python {PYTHON_VERSION}")
    target_exe = python_binary(plat)
    if target_exe.exists() and not force:
        Log.ok(f"Already installed: {target_exe}")
        return True

    url = (
        "https://github.com/astral-sh/python-build-standalone/releases/download/"
        f"{PYTHON_BUILD_TAG}/"
        f"cpython-{PYTHON_VERSION}%2B{PYTHON_BUILD_TAG}-"
        f"{plat['python_triple']}-install_only_stripped.tar.gz"
    )
    archive = DOWNLOADS / f"python-{PYTHON_VERSION}-{plat['python_triple']}.tar.gz"

    try:
        download(url, archive, force=force,
                 expected_min_size=MIN_SIZE_PYTHON_ARCHIVE,
                 label="portable Python")
    except RuntimeError as e:
        Log.error(str(e)); return False

    Log.info("Extracting Python")
    try:
        tmp = _extract_to_temp(archive, "tar.gz")
    except Exception as e:
        Log.error(f"Extraction failed: {e}"); return False

    target = RUNTIME / "python"
    try:
        root = _find_extract_root(tmp)
        if target.exists():
            shutil.rmtree(target, ignore_errors=True)
        shutil.move(str(root), str(target))
    except Exception as e:
        Log.error(f"Could not place Python: {e}")
        shutil.rmtree(tmp, ignore_errors=True); return False
    finally:
        shutil.rmtree(tmp, ignore_errors=True)

    if not target_exe.exists():
        Log.error(f"Python executable not found: {target_exe}"); return False

    ok, detail = _verify_python(target_exe)
    if not ok:
        Log.error(f"Python verification failed: {detail}"); return False

    Log.ok(f"Python installed at {target_exe}  ({detail})")
    return True

_installed_php_version: Optional[str] = None


def _install_php_unix(plat, force):
    Log.title("PHP runtime (static-php-cli)")
    cgi_exe = php_cgi_binary(plat)
    cli_exe = php_cli_binary(plat)
    if cgi_exe.exists() and not force:
        Log.ok(f"Already installed: {cgi_exe}")
        return True

    last_error = None
    for version in PHP_UNIX_VERSION_CANDIDATES:
        archive_name = f"php-{version}-cli-{plat['php_os']}-{plat['php_arch']}.tar.gz"
        url = (f"https://dl.static-php.dev/static-php-cli/bulk/"
               f"{plat['php_os']}-{plat['php_arch']}/{archive_name}")
        archive = DOWNLOADS / archive_name

        Log.info(f"Trying PHP {version}")
        try:
            download(url, archive, force=force,
                     expected_min_size=MIN_SIZE_PHP_UNIX_ARCHIVE,
                     label=f"portable PHP {version}")
        except RuntimeError as e:
            last_error = str(e); continue

        Log.info(f"Extracting PHP {version}")
        try:
            tmp = _extract_to_temp(archive, "tar.gz")
        except Exception as e:
            last_error = f"extraction failed: {e}"; continue

        target = RUNTIME / "php"
        try:
            entries = list(tmp.iterdir())
            target.mkdir(parents=True, exist_ok=True)
            if len(entries) == 1 and entries[0].is_file():
                shutil.move(str(entries[0]), str(target / entries[0].name))
            else:
                root = _find_extract_root(tmp)
                for item in root.iterdir():
                    dest = target / item.name
                    if dest.exists():
                        if dest.is_dir():
                            shutil.rmtree(dest)
                        else:
                            dest.unlink()
                    shutil.move(str(item), str(dest))
        except Exception as e:
            Log.error(f"Could not place PHP: {e}")
            shutil.rmtree(tmp, ignore_errors=True); continue
        finally:
            shutil.rmtree(tmp, ignore_errors=True)

        if not cgi_exe.exists():
            last_error = f"php-cgi not found at {cgi_exe}"; continue

        try:
            cgi_exe.chmod(cgi_exe.stat().st_mode | 0o755)
            cli_exe.chmod(cli_exe.stat().st_mode | 0o755)
        except OSError:
            pass

        ok, detail = _verify_php_cgi(cgi_exe)
        if not ok:
            last_error = f"verification failed: {detail}"; continue

        global _installed_php_version
        _installed_php_version = version
        Log.ok(f"PHP {version} installed at {cgi_exe}")
        return True

    Log.error(f"All PHP versions failed. Last error: {last_error}")
    return False


def _windows_vs_variants(version):
    try:
        parts = version.split(".")
        major, minor = int(parts[0]), int(parts[1])
        if major > 8 or (major == 8 and minor >= 4):
            return ["vs17", "vs16"]
    except Exception:
        pass
    return ["vs16", "vs17"]


def _install_php_windows(plat, force):
    Log.title("PHP runtime (official Windows build)")
    cgi_exe = php_cgi_binary(plat)
    cli_exe = php_cli_binary(plat)

    if cgi_exe.exists() and cli_exe.exists() and not force:
        Log.ok(f"Already installed: {cgi_exe}")
        # Make sure php.ini is present too.
        if not (RUNTIME / "php" / "php.ini").exists():
            Log.info("php.ini is missing - writing a fresh one")
            _write_php_ini(RUNTIME / "php")
        return True

    last_error = None
    for version in PHP_WINDOWS_VERSION_CANDIDATES:
        for vs in _windows_vs_variants(version):
            for folder in PHP_WINDOWS_URL_FOLDERS:
                archive_name = f"php-{version}-Win32-{vs}-x64.zip"
                url = (f"https://windows.php.net/downloads/{folder}/{archive_name}")
                archive = DOWNLOADS / archive_name

                Log.info(f"Trying PHP {version} ({vs}, {folder})")
                try:
                    download(url, archive, force=force,
                             expected_min_size=MIN_SIZE_PHP_WINDOWS_ARCHIVE,
                             label=f"PHP {version}")
                except RuntimeError as e:
                    last_error = str(e); continue

                Log.info(f"Extracting PHP {version}")
                target = RUNTIME / "php"
                target.mkdir(parents=True, exist_ok=True)
                try:
                    with zipfile.ZipFile(archive, "r") as zf:
                        _safe_extract_zip(zf, target)
                except Exception as e:
                    last_error = f"extraction failed: {e}"; continue

                if not cli_exe.exists():
                    last_error = f"php.exe not found"; continue
                if not cgi_exe.exists():
                    last_error = f"php-cgi.exe not found"; continue

                ok, detail = _verify_php_cgi(cgi_exe)
                if not ok:
                    last_error = f"php-cgi.exe verification failed: {detail}"
                    continue

                # Write php.ini so extensions load.
                Log.info("Writing php.ini")
                _write_php_ini(target)

                global _installed_php_version
                _installed_php_version = version
                Log.ok(f"PHP {version} installed")
                Log.ok(f"  CLI: {cli_exe}")
                Log.ok(f"  CGI: {cgi_exe}")
                Log.ok(f"  {detail}")
                return True

    Log.error(f"All PHP versions failed. Last error: {last_error}")
    return False


def install_php(plat, force):
    if plat["is_windows"]:
        return _install_php_windows(plat, force)
    return _install_php_unix(plat, force)

def install_python_deps(plat):
    Log.title("Python dependencies")
    exe = python_binary(plat)
    if not exe.exists():
        Log.error(f"Portable Python not found: {exe}"); return False
    if not REQUIREMENTS.exists():
        Log.error(f"requirements.txt not found: {REQUIREMENTS}"); return False

    try:
        subprocess.check_call([str(exe), "-m", "pip", "--version"],
                              stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
    except (subprocess.CalledProcessError, FileNotFoundError):
        Log.info("pip not found - running ensurepip")
        try:
            subprocess.check_call([str(exe), "-m", "ensurepip", "--upgrade"],
                                  stdout=subprocess.DEVNULL)
        except subprocess.CalledProcessError as e:
            Log.error(f"ensurepip failed: {e}"); return False

    Log.info("Upgrading pip")
    try:
        subprocess.check_call([str(exe), "-m", "pip", "install", "--upgrade", "pip"],
                              stdout=subprocess.DEVNULL)
    except subprocess.CalledProcessError as e:
        Log.warn(f"pip upgrade failed (continuing): {e}")

    Log.info(f"Installing {REQUIREMENTS.name}")
    try:
        subprocess.check_call([str(exe), "-m", "pip", "install",
                               "-r", str(REQUIREMENTS)])
    except subprocess.CalledProcessError as e:
        Log.error(f"pip install failed: {e}"); return False

    Log.ok("Python dependencies installed")
    return True

def cmd_check(plat):
    Log.title("Runtime status")
    all_ok = True

    py = python_binary(plat)
    if not py.exists():
        Log.error(f"Python: missing ({py})"); all_ok = False
    else:
        ok, detail = _verify_python(py)
        (Log.ok if ok else Log.error)(f"Python: {py}" + (f"  ({detail})" if ok else f" - {detail}"))
        if not ok: all_ok = False

    php_cli = php_cli_binary(plat)
    if php_cli.exists():
        Log.ok(f"PHP CLI: {php_cli}")
    else:
        Log.warn(f"PHP CLI: missing ({php_cli})")

    php_cgi = php_cgi_binary(plat)
    if not php_cgi.exists():
        Log.error(f"PHP CGI: missing ({php_cgi})"); all_ok = False
    else:
        ok, detail = _verify_php_cgi(php_cgi)
        if ok:
            Log.ok(f"PHP CGI: {php_cgi}")
            Log.ok(f"  {detail}")
        else:
            Log.error(f"PHP CGI: {php_cgi} - {detail}"); all_ok = False

    # Check php.ini presence.
    ini = RUNTIME / "php" / "php.ini"
    if ini.exists():
        Log.ok(f"php.ini: {ini}")
    else:
        Log.warn(f"php.ini: missing ({ini})")
        Log.warn("  Extensions may not load. Run:")
        Log.warn("      python bootstrap/setup.py --force --skip-python --skip-sqlite --skip-deps --skip-vendor")

    sqlite = sqlite_binary(plat)
    if sqlite.exists():
        Log.ok(f"SQLite CLI: {sqlite}")
    else:
        Log.warn(f"SQLite CLI: missing ({sqlite})")

    runtime_env = RUNTIME / "runtime.env"
    if runtime_env.exists():
        Log.ok(f"Manifest: {runtime_env}")

    print()
    if all_ok:
        Log.ok("Runtime is fully installed.")
        return 0
    Log.warn("Runtime is incomplete. Run: python bootstrap/setup.py")
    return 1

def parse_args():
    p = argparse.ArgumentParser(prog="bootstrap/setup.py")
    p.add_argument("--force", action="store_true")
    p.add_argument("--skip-python", action="store_true")
    p.add_argument("--skip-php", action="store_true")
    p.add_argument("--skip-sqlite", action="store_true")
    p.add_argument("--skip-deps", action="store_true")
    p.add_argument("--skip-vendor", action="store_true")
    p.add_argument("--check", action="store_true")
    p.add_argument("--verbose", action="store_true")
    return p.parse_args()


def main():
    if sys.version_info < (3, 8):
        sys.stderr.write("Requires Python 3.8+\n"); return 2

    args = parse_args()
    plat = detect_platform()

    Log.banner()
    Log.info(f"Detected platform: {plat['system']}-{plat['arch']}")
    Log.info(f"Project root: {ROOT}")
    Log.info(f"Runtime dir:  {RUNTIME}")

    RUNTIME.mkdir(exist_ok=True)
    DOWNLOADS.mkdir(exist_ok=True)

    if args.check:
        return cmd_check(plat)

    results = {}

    results["Python"] = (
        install_python(plat, force=args.force)
        if not args.skip_python else None
    )
    if args.skip_python: Log.warn("Python installation skipped")

    results["PHP"] = (
        install_php(plat, force=args.force)
        if not args.skip_php else None
    )
    if args.skip_php: Log.warn("PHP installation skipped")

    results["SQLite"] = (
        install_sqlite(plat, force=args.force)
        if not args.skip_sqlite else None
    )
    if args.skip_sqlite: Log.warn("SQLite installation skipped")

    python_ok = results.get("Python") is True or (
        results.get("Python") is None and python_binary(plat).exists()
    )

    if python_ok:
        if not args.skip_deps:
            results["Dependencies"] = install_python_deps(plat)
        if not args.skip_vendor:
            results["LiteGraph"] = download_vendor(plat)
        write_runtime_env(plat)
    else:
        Log.error("Skipping dependencies and vendor - Python is not installed.")

    Log.title("Summary")
    exit_code = 0
    for name, ok in results.items():
        if ok is True:    Log.ok(f"{name}")
        elif ok is False: Log.error(f"{name}"); exit_code = 1
        else:             Log.warn(f"{name} (skipped)")

    print()
    if exit_code == 0:
        Log.ok("Bootstrap complete.")
        print()
        print("  Next steps:")
        print("      start.bat" if plat["is_windows"] else "      ./start.sh")
        print()
    else:
        Log.error("Bootstrap finished with errors.")
        print()
        print("  To retry: python bootstrap/setup.py --force")
        print()

    return exit_code


if __name__ == "__main__":
    try:
        sys.exit(main())
    except KeyboardInterrupt:
        print(); Log.warn("Interrupted."); sys.exit(130)
    except SystemExit:
        raise
    except Exception as e:
        Log.error(f"Unexpected error: {e}")
        if "--verbose" in sys.argv:
            import traceback; traceback.print_exc()
        sys.exit(1)
